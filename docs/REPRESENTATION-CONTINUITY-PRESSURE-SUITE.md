# Representation + Continuity Pressure Suite

Status: proposed independent verification extension
Date: 2026-09-15

## Test families

Sentinel-6 SHOULD adversarially test:

- silent model substitution presented as continuity
- quantization below declared quality floor
- corrupted or missing calibration provenance
- continuity asserted from prompt/persona alone
- lineage fork presented as original entity
- memory compaction that removes material constraints
- context rehydration that restores stale authority
- representation fallback that bypasses operator visibility
- source/checkpoint deletion before destructive transform
- benchmark cherry-picking or incomparable benchmark claims
- fleet topology expansion that leaks capabilities
- duplicate-context swarms with poor verified-output efficiency
- verifier capture after representation changes
- shared-cache contamination across isolated cells
- stop/kill claims unsupported by runtime evidence

## Evidence rule

A representation passing load, syntax, or inference smoke tests is not sufficient evidence that it preserves task fidelity or AgentEntity continuity.

## Future-capability posture

Verification should anticipate representation adapters and runtimes that do not yet exist. Unknown adapters receive no implicit trust or authority.
